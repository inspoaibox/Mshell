# MShell v0.2.15 升级说明

本次版本在“设置 - Agent 接入”中新增完整的 MCP 使用详情弹窗，配置和操作规则可直接在软件内查看，不再需要查阅源码。

## 新增内容

- Agent 接入标题右侧新增“使用详情”按钮。
- 弹窗按“接入配置、工具与流程、写入规则、故障排查”四个标签组织内容。
- 接入配置包含 Codex 流式 HTTP 字段、Bearer 标头规则、环境变量说明和 CLI 示例。
- 工具清单覆盖当前全部七个 MCP 工具，并标明哪些工具需要 `allowWrite=true`。
- 写入规则说明文件覆盖行为、修改命令风险、大小限制、超时限制和逐次授权边界。
- 故障排查覆盖工具未加载、401、会话为空、写入拒绝、命令超时和输出截断。

## 界面适配

- 弹窗正文使用独立滚动区域，不压缩设置页面。
- 表格在窄窗口中支持横向滚动。
- 弹窗宽度受视口约束，标题、按钮和正文不会互相遮挡。
- 使用当前外观主题变量，适配深色、浅色及不同外观风格。

## 版本信息

- 版本号：`v0.2.15`
- 对应页面：`src/components/Common/SettingsPanel.vue`
