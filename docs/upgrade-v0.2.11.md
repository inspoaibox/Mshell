# MShell v0.2.11 升级说明

本次版本补充安全产品使用说明书，并完善本机 Agent / MCP 只读接入的公开使用文档，帮助用户在启用远程管理能力前明确安全边界、配置方法和故障处理流程。

## 本次更新

- 新增安全产品使用说明书，覆盖 Windows、Android、SSH、SFTP、密钥、会话锁、备份、同步、日志和高风险操作。
- 补充 MCP 完整使用流程：启用服务、令牌管理、Codex 配置、Claude 配置、首次验证、工具调用顺序、重连行为、停止服务和故障排查。
- 在 GitHub README、docs 文档索引和文档首页增加安全说明入口。
- 统一应用设置页、文档站和安装包使用的版本号为 `v0.2.11`。

## 安全说明

- MCP 默认关闭，仅绑定本机回环地址，并且只提供已连接 SSH 会话的只读能力。
- MCP 不支持远程命令执行、文件写入、上传、删除、权限修改，也不会返回 SSH 密码或私钥。
- 安全说明书同时列出当前实现限制，包括 safeStorage 不可用时的 Base64 降级、备份/同步的 AES-CBC 防篡改限制和日志脱敏边界。
