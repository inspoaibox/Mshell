# MShell v0.2.16 升级说明

本次版本将 MCP 写入授权从“每次工具调用传参”改为 MShell 设置中的独立持久开关，减少重复确认，同时把最终控制权放在本机服务端。

## 设置开关

- “设置 - Agent 接入”新增“允许写入与修改”。
- 开关默认关闭，旧版本配置升级后也保持关闭。
- 关闭时，write_remote_file 和 execute_command 由 MShell 服务端拒绝。
- 开启后，Agent 可以连续完成当前任务所需的写文件和修改命令，不需要重复传 allowWrite 参数。
- 设置保存在本机，重启 MShell 后保持上次状态；完成任务后建议关闭。

## 兼容规则

- 原有会话读取、目录读取、文本读取和白名单查询不受影响。
- 旧客户端即使继续传入 allowWrite=true，也不能绕过关闭状态。
- 新客户端在开关开启后可以省略 allowWrite 参数。
- 开关改变后立即生效，不要求重启 MCP 服务或重新连接 SSH。

## 安全说明

- 写入开关不是第二个密码。开启期间，持有当前 MCP Token 的客户端可以调用写入工具。
- 写入工具仍记录成功和失败审计，修改命令正文不会以明文写入审计日志。
- 高风险修改前建议备份，任务完成后关闭写入开关并检查结果。
