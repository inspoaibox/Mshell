# MShell v0.2.22 升级说明

本次更新新增会话与分组置顶，完善排序和实时监控，并集中修复跳板机连接、懒人脚本、终端搜索、命令智能、防火墙及 Docker 管理中的问题。

## 会话管理与排序

- 分组右键菜单新增“置顶／取消置顶”“上移”“下移”，到达边界时自动禁用对应移动操作。
- 单个会话右键菜单新增“置顶／取消置顶”，支持分组内会话和未分组会话。
- 置顶的分组与会话显示置顶标识。置顶会话排在所属分组前面，不改变会话的分组归属。
- 分组上下移动、会话拖拽排序分别在置顶项或普通项之间进行，保持置顶项优先显示。
- 修复会话拖拽后列表未按保存顺序显示，以及未分组会话无法正确拖拽排序的问题。
- 搜索状态下按会话 ID 确定拖拽目标，避免因部分会话被隐藏而调整错误的会话。
- 置顶状态和排序立即生效，重启后保留，并支持备份恢复、同步和导入导出。保存失败时提示错误，不显示为操作成功。

## SSH 与跳板机连接

- 完善连接超时、取消和失败清理，修复通过跳板机连接时长时间停留在 Connecting、没有明确结果的问题。
- 改进连接失败后的资源释放与状态反馈，避免旧连接过程继续影响后续连接。

## 懒人脚本

- 执行时固定所选脚本及参数，避免上传期间切换脚本后执行内容与原操作不一致。
- 使用部署返回的实际绝对路径执行和清理脚本，修复切换终端用户后因主目录不同而出现 `.run-*.sh: No such file or directory` 的问题，包括添加 SSH 公钥的执行场景。
- 部署失败、连接断开或任务取消后停止后续执行，并根据脚本退出状态显示执行结果。
- 改进参数替换、密码字段处理和脚本库变更刷新，保留用户自定义脚本内容。

## 终端搜索与命令智能

- 搜索命中后定位并高亮对应内容，提供匹配导航和位置反馈。
- 普通终端搜索范围包含已保留的滚动历史；Vim、Nano 等全屏程序仅能搜索当前终端画面，搜索完整文件仍需使用编辑器自身的搜索功能。
- 完善快捷命令、历史命令和路径补全，以及 `#` AI 命令建议、`?命令` 解释的输入处理。
- 丢弃过期的 AI 响应，避免切换会话或修改输入后出现旧建议；改善请求失败后的提示与重试。
- 在编辑器和密码提示等场景中避免补全干扰，并防止查询文本误提交或建议命令重复执行。

## 实时监控

- 核心指标默认每 1 秒刷新，支持选择 1、2、3、5 秒间隔并保存偏好。
- 展示 CPU、内存趋势以及网络速率、进程等信息；按采样差值计算相关指标。
- 磁盘信息每 10 秒、进程信息每 5 秒采集，减少频繁执行远程命令的开销。
- 改进慢请求、断线重连和异常数据的处理，提供采样中、过期及错误状态反馈。

## 防火墙与 Docker 管理

- 防火墙修改前重新检查当前连接与规则状态，保护当前 SSH 所需规则，避免使用过期检测结果执行操作。
- 完善防火墙后端识别、规则校验、操作后验证及失败提示，区分权限不足、检测不完整等情况。
- Docker 管理支持每 5 秒自动刷新，可关闭自动刷新并保留手动刷新；后台暂停、重连恢复及慢请求处理更加完善。
- 修复 Docker 项目操作受搜索或状态筛选影响、只处理部分容器的问题，确认时说明完整操作范围。
- 区分 Docker 操作成功、部分成功和失败，改善容器及关联资源清理后的结果反馈。

## 界面可读性

- 调整删除等危险操作按钮的背景、文字、边框及交互状态配色。
- 改善深色、浅色和各外观风格下红色按钮的文字对比度。

## Agent / MCP 权限与执行控制

- 明确区分只读查询工具和写入执行工具，并向 Agent 提供只读、危险操作标识，减少工具误选。
- “执行”模式仍遵守只读命令白名单；新增 PM2 只读查询支持，允许 `pm2 list`、`pm2 jlist`、`pm2 describe` 等查询，拒绝启动、停止、重启和删除。
- 从“执行”或“确认”切回“查询”时，仍在等待或执行中的写请求会收到取消信号；已经在远程服务器完成的操作无法自动回滚。
- 完善 Agent 使用说明、权限提示和 MCP 测试，保持数据库查询在三档模式下只读。
